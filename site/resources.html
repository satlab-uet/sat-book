2. Open-Source Solvers & Software

SCLib — Shared Counter Library (C++)

C++ LIBRARY

High-performance C++ header-only library for generating sequential counter encodings, ladder-shaped AMO/AMK cardinality constraints, and Pseudo-Boolean translations.

MaxSAT-DDD Train Rescheduling Engine

DECISION ENGINE

Dynamic Decoupled Domain reasoning engine integrated with MaxSAT solvers for real-time railway train dispatching and rescheduling under track conflicts.
